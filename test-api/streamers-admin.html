Войти через Twitch →
Стримерский баланс не связан с личными монетами пользователей. Пополнение задаёт бюджет канала вручную. Эта версия работает в тестовой инфраструктуре, без реальной выдачи скинов.

Пополнение и резерв каждого дропа сохраняются отдельными операциями.
