# Live

`/live` — ставки монетами на события матча D1PSY vs ENEMY. `/admin/live` — ручное управление доступностью и результатами и журнал всех ставок (по 50 на страницу). Логотипы находятся в `assets/live`.

Одна ставка содержит один исход одного события, целую сумму от 5 до 150 монет и зафиксированный сервером коэффициент. Можно делать несколько отдельных ставок, в том числе на одно событие. Сумма списывается при приёме. Выигрыш — `round(stake * odds)` (полная выплата, включая ставку); проигрыш — 0. Отмена и ничья в основном времени возвращают ставку. «Килл любой гранатой» включает любой тип гранаты. Результаты указывает администратор.

`rewards_live_place_bet` блокирует событие и пользователя, проверяет ограничения аккаунта, версию события, баланс и допустимый исход. Повтор одного request UUID возвращает прежнюю ставку без нового списания; изменение тела с тем же UUID отклоняется. Ставки и расчёты используют существующий `rewards_coin_transactions`; streamer balance не участвует.

Публикация результата рассчитывает ожидающие ставки в одной транзакции через триггер, включая запросы старой версии сервера при обновлении. Рассчитанный результат менять нельзя. Выбор «Без результата» после расчёта начинает новое поколение события; старые ставки и выплаты сохраняются. Закрытие без результата временно останавливает приём и не отменяет ставки.

Таблицы и функции доступны только серверной service_role, защищены RLS и REVOKE для клиентов. HTTP использует существующие пользовательскую и административную сессии, проверку Origin, JSON, строгую форму ставки и no-store. Пользователь видит последние 100 своих ставок, администратор — все через пагинацию; обновление каждые 5 секунд.

Проверки: PGlite для реального списания/расчёта/возвратов/прав/идемпотентности; Express и JSDOM для сессий, административных прав, конфликтов версии, одного исхода, нескольких отдельных ставок и журнала.
