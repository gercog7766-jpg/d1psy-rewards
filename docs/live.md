# Live — демонстрационный режим

`/live` — шесть событий матча d1psy vs enemy. `/admin/live` — отдельная вкладка в админке. При первой публикации все кнопки закрыты, результатов нет.

Коэффициенты фиксированы в `src/live-markets.ts`. Исход матча учитывает овертаймы, основное время — нет. Тотал 18.5 относится к общему числу раундов матча: больше от 19, меньше до 18. ACE — пять убийств одним игроком за раунд, нож — минимум одно убийство ножом, граната — минимум одно убийство HE. Все факты и результаты указывает администратор вручную, внешние источники не подключены.

В админке каждое событие сохраняется отдельно: выберите доступность и результат, нажмите «Сохранить» перед редактированием следующего события. Выбранный результат закрывает событие; для открытия результат очищается. Для основного времени предусмотрена ничья, для всех событий — отмена. Для следующего матча очистите результаты и откройте нужные события. Версия строки защищает от одновременного перезаписывания другим администратором.

Выбор пользователя существует только в памяти страницы, не сохраняется на сервере, не оплачивается и не приносит наград. Нет ставок, купонов, расчётов выплат, монет, XP или заданий Battle Pass. Изменения администратора появляются у пользователя при опросе раз в пять секунд; при ошибке загрузки пользовательские кнопки блокируются.

Таблица `rewards_live_test_markets` закрыта RLS и недоступна anon/authenticated. Сервер читает состояние после проверки сессии, изменяет только после проверки администратора, Origin, JSON и допустимого исхода. Страницы и API не кэшируются; сессии PWA восстанавливаются для Live и вложенных страниц админки.

Проверки: изолированный PGlite для ограничений/прав, настоящий Express с подставным PostgREST и JSDOM для закрытых кнопок, открытия администратором, выбора без записи, результатов, конфликтов версий и защиты API.
