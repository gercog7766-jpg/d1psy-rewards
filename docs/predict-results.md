# Результаты предиктов и получение монет

Завершённый матч показывает фактический счёт в порядке команд карточки, зелёного победителя и красного проигравшего (цвета дополнены текстом/иконками). Выбранная неверная команда/счёт помечаются красным. В строке игрока два поля: слева сохранённый выбор пользователя, справа фактический лучший игрок/игроки. Без прогноза показано «Нет прогноза».

Расчёт: победитель +3, точный счёт в пользу победившей команды ещё +3, лучший игрок +4 независимо от команды. При сумме >0 доступна кнопка «Забрать N монет», при 0 вместо неё в нижнем блоке показано «Матч окончен». После получения показано «Получено». Матч без личного прогноза не даёт награду.

`rewards_settle_predictions` фиксирует результат и компоненты награды, но больше не пишет ledger автоматически. `rewards_claim_prediction` берёт пользователя из серверного API, проверяет завершённость, блокирует его prediction FOR UPDATE и за одну транзакцию создаёт ledger-запись/claimed_at. Повторное нажатие, повтор после потери ответа и несколько вкладок возвращают уже полученную награду. Ранее автоматически зачисленные награды мигрируются как полученные и повторно не выдаются. Ошибка ledger откатывает получение целиком. RLS/service-only RPC и проверка Origin/JSON на API.

Для внесения результата используется существующий admin-only settlement API или серверный SQL RPC. Исправление уже подтверждённого результата другим значением запрещено. Завершение матча продолжает обновлять существующий Battle Pass-триггер; claim не повторяет событие settlement.

Результат, предоставленный владельцем для первого матча: `2026-11-06-parivision-navi`, победитель `b` (Natus Vincere), счёт `2:1` в пользу победителя, лучший игрок `w0nderful`. Второй матч не рассчитывается до отдельного результата.

Релиз: применить `20261106102846_predict_claim_rewards.sql`, опубликовать сервер, внести результат через settlement RPC. Новых env vars нет. В клиент передаётся только claimed_at; идентификатор транзакции и чужие прогнозы не раскрываются.

Проверки: новый SQL-тест покрывает ожидающие награды 10/7/4/6/3/0, старые кредиты, блокировки ролей, чужие/отсутствующие прогнозы, rollback и параллельные повторные claims. Полный Express/PGlite/JSDOM проверяет цвета и игрока, потерю ответа, повторное получение без дубля, reload, нулевой прогноз, неподписанного пользователя, Origin и игнорирование подмены userId/amount. Скриншотная проверка в браузере не проводилась.
