# Пользователи и приватность

`/users` — каталог участников с поиском по имени и логину, онлайн первыми и пагинацией по 24 записи. `/users/:login` показывает имя, аватар и инвентарь с ценами в монетах, без действий, торговых ссылок и истории.

Профили по умолчанию публичные. Переключатель «Приватный профиль» доступен владельцу; настройка общая для сайта и PWA. Имя, аватар и онлайн остаются в каталоге. Сервер скрывает предметы и их количество от остальных пользователей, включая прямой API-запрос. Владелец видит свой инвентарь. Страница обновляет данные каждые 30 секунд и при возврате во вкладку; предыдущие предметы очищаются перед загрузкой.

Онлайн определяется видимой вкладкой сайта, а не Twitch. Heartbeat раз в 30 секунд привязан к авторизованной сессии устройства и случайному идентификатору вкладки. Скрытие/закрытие вкладки удаляет только её запись; остальные вкладки и устройства учитываются отдельно. Запись истекает через две минуты без heartbeat. Выход/истечение сессии исключают устройство из онлайн-статуса.

Таблица presence закрыта RLS; функции доступны только service_role. HTTP-обработчики берут владельца из подписанной сессии, проверяют Origin и тип JSON для изменений. Личные HTML/API не кэшируются.

Проверки: PGlite для приватности, выборки предметов, прав доступа и TTL; настоящий Express с изолированной базой и JSDOM для каталога, профиля, переключателя и API. Визуальная проверка настоящего мобильного устройства не выполнялась.

Публичный инвентарь включает предметы до отправки: pending/awaiting_choice без delivered_at. Проданные, использованные, отправленные/полученные предметы и отменённые заказы исключаются сервером, в том числе из счётчика и пагинации. Цена — sell_price_coins предмета, для старых покупок без связанного выигрыша — price_coins заказа. Приватный инвентарь и цены скрыты.

## Партнёрские профили

Каталог и профиль показывают отметку «Стример» для основного канала и одобренных подключений из rewards_streamer_live_profiles. Сервер сопоставляет записи через неизменяемый Twitch ID пользователя; pending/rejected не получают отметку. Статус не зависит от включения розыгрышей. При ошибке чтения статуса API возвращает 503. Выборки ограничены пользователями текущей страницы, служебные поля стримеров в ответ не включаются.

Партнёрский профиль выделен шапкой с подписью «ПАРТНЁР D1PSY REWARDS», ссылкой на Twitch и переходом к каталогу стримеров. Онлайн означает присутствие на сайте. Приватность инвентаря и цели сохраняется. Изменение не требует миграции.
