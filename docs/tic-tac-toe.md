# Бесплатные онлайн-крестики-нолики

`/games/tic-tac-toe`, карточка в разделе «Игры». Игра не использует монеты: нет ставок, списаний, комиссий или начислений.

Публичные столы видны в общем списке. Приватные доступны по ссылке и паролю (4–64 символа), в списке не показываются. Пароль не включается в URL и хранится только как HMAC-SHA256 с отдельным контекстом комнаты и серверным SESSION_SECRET. Смена SESSION_SECRET сделает старые пароли недействительными; ожидающие комнаты живут 15 минут. Не публиковать ключи и пароли в логах. Подбор ограничен 10 входами в минуту на аккаунт.

Хост создаёт стол, второй игрок подключается. X/O распределяются сервером случайно, X ходит первым. На ход 60 секунд. По истечении времени — техническое поражение. Отмена ожидающего стола и сдача во время игры предусмотрены. Перезагрузка и перезапуск приложения не теряют состояние. Последние 10 своих партий показаны под полем.

Ходы, очередь, занятость клетки и версия поля проверяются функцией PostgreSQL под блокировкой строки комнаты. Одновременный вход двух соперников допускает только одного. Создание/вход блокируют строку пользователя для ограничения одной текущей партией. Повтор создания с тем же UUID безопасен; повтор хода со старой revision отклоняется. Истечение таймера проверяется по часам базы, состояние обновляется при чтении; отдельный cron не требуется.

Клиент опрашивает сервер раз в 2,5 секунды, время отображает с поправкой на серверные часы. После действия состояние перечитывается сразу. Пароль при обновлении поля не теряет фокус ввода. Прямой доступ anon/authenticated к таблице и RPC запрещён, сервер использует service_role и пользователя из подписанной Twitch-сессии. Приватное поле не передаётся посторонним.

Перед публикацией применяется `supabase/migrations/20261105223516_tic_tac_toe_rooms.sql`, затем обычный deploy Render. Новые переменные не нужны.

Проверки: npm test, npm run typecheck, npm run build. SQL-тест проверяет конкурентное присоединение, приватность, пароль, все переходы очереди, дубли ходов, победу, ничью, таймаут, отмену, сдачу, истечение ожидания и права ролей. HTTP-проверка полного приложения подтверждает signed-session identity и безопасную передачу HMAC вместо пароля в базу. В DOM проверены карточка, приглашение, вход, поле, соответствие X/O, фокус пароля и результат. Визуальная проверка Chromium в этой среде недоступна (процесс завершается при запуске).
