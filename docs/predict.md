# Предикт

`/predict` — карточки матчей BO3: победитель, счёт 2:0/2:1 в пользу выбранного победителя, лучший по киллам игрок из обеих пятёрок.

Стартовые матчи: 06.11.2026 PARIVISION — Natus Vincere 09:30 МСК (06:30 UTC); BETBOOM — FURIA 12:30 МСК (09:30 UTC). В браузере даты и время отображаются локально. Приём закрывается соответственно в 09:15 и 12:15 МСК. Без X2 и билетов.

Прогнозы можно менять до старта минус 15 минут. База проверяет часы после получения блокировки матча. Пользователь определяется сервером по подписанной Twitch-сессии. Прямой доступ anon/authenticated к таблицам и функциям запрещён. API возвращает только собственный прогноз пользователя.

Начисления через существующий rewards_coin_transactions: +3 за победителя, +3 за полный точный результат (правильный победитель и счёт), +4 за игрока по киллам, максимум 10. При равном максимуме киллов можно указать несколько игроков; попадание в любой из них засчитывается. Нет списаний или платы за прогноз. Награды выдаются одной транзакцией с итогом матча. Повторное подтверждение того же результата безопасно; противоречащий результат отклоняется.

## Добавление матчей и результатов по данным владельца

Матчи живут в `rewards_predict_matches` отдельно от кода. Новые матчи добавляются SQL insert с уникальным `id`, временем `starts_at` в UTC, названиями команд, путями логотипов и двумя массивами ровно по 5 никнеймов. Название турнира необязательно (по умолчанию CS2), реальные названия не выдумываются. Не менять составы/сроки после закрытия приёма без отдельного решения владельца.

Когда владелец предоставит итог, вызвать `rewards_settle_predictions(p_match_id, p_winner, p_score, p_top_players)` серверным доступом. `p_winner`: a или b, счёт 2:0 либо 2:1 в пользу победителя, массив лучших по киллам, например `{Jame}`. Администратор с подписанной сессией также может отправить POST `/api/admin/predict/:id/settle` с JSON `{winner,score,topPlayers}`. Обычный пользователь не может подтверждать результат. Повторный несовпадающий итог не исправляется автоматически.

Публикация: применить `supabase/migrations/20261105213416_predict_matches.sql`, развернуть обычный сервис Render. Новые переменные не нужны. Откат кода не требует удаления таблиц или данных.

Проверки: `npm test`, `npm run build`, `npm run typecheck`. SQL-тесты изолированно проверяют даты/составы, изменение одного прогноза, невалидный ввод, точную границу дедлайна, все комбинации наград, повторную обработку и откат при ошибке журнала монет, равных лидеров и права ролей.

Логотипы скачаны по предоставленным владельцем адресам и включены в `assets/teams`. Исходники: Cybersport.ru (PARIVISION), Wikimedia (Natus Vincere, BETBOOM, FURIA). При недоступном изображении интерфейс показывает сокращение названия команды.

## Админка предиктов

Вкладка «Предикты» на `/admin` открывает `/admin/predict`. Доступ проверяется существующей подписанной Twitch-сессией и таблицей администраторов. Можно добавить BO3-матч в IEM Beijing или BLAST Rivals 2026 Season 2: команды, необязательные HTTPS-логотипы, составы по 5 уникальных игроков и местное время начала (сервер хранит UTC). Создание возможно до закрытия приёма; стабильный ID защищает повторную отправку. Существующие матчи не перезаписываются.

В карточке матча администратор выбирает победителя, счёт в пользу победителя и лучшего по киллам (несколько при равенстве), проверяет итог в подтверждении и публикует его через существующий атомарный settlement RPC. Другой результат после подтверждения отклоняется. Матч можно отменить: условное обновление только scheduled не позволяет отменить уже рассчитанный матч. Удаления прогнозов и ручного вмешательства в балансы нет. POST защищены проверкой Origin и JSON.
