# XP за игру и ежедневные задания Battle Pass

Победа в крестиках-ноликах с момента выпуска даёт +10 XP к уровню аккаунта, максимум 30 XP за московский день. Учитывается обычная победа, сдача соперника и техническая победа по таймауту; ничья и отмена ожидающего стола не дают XP. Ранее завершённые партии не пересчитываются. Событие XP уникально по user/source_type/room UUID и записывается в одной транзакции с завершением партии.

С 07.11.2026 00:00 МСК новые ежедневные задания: `ttt_win` — выиграть партию; `wordly_win` — угадать слово; `predict_winner` — правильно выбрать победителя матча. Цель каждого — 1, награда каждого — 150 SP. Это тройка заданий на 7 ноября. Начиная с 8 ноября новые задания участвуют в общем пуле ежедневной ротации. Всегда три задания в день, дропы по воскресеньям исключаются. День 6 ноября и прошлые дни сохраняются.

Прогноз засчитывается после подтверждения итогов матча, а не при отправке. Для задания достаточно верного победителя, точный счёт/килл-лидер не обязательны. Учитывается московский день подтверждения. Ежедневная награда за задание выдаётся только один раз; следующие победы продолжают давать XP за крестики-нолики, но не повторяют SP того же дня.

Расписание `rewards_season_daily_schedule` теперь является источником ежедневных заданий и для базы, и для API. В ответе API сохраняются title, target, reward, progress, complete, done. Перезапуск генератора не переписывает уже начавшийся день.

Взаимодействие создания/входа в комнаты с XP: прежняя блокировка строки аккаунта заменена на транзакционную advisory-блокировку на пользователя. Ограничение одной текущей комнаты сохранено; исключён обратный порядок блокировок аккаунт/комната при начислении XP.

Перед выпуском кода применить `supabase/migrations/20261105225435_game_xp_battle_pass.sql`. Новые переменные и расписания ChatGPT не нужны: активация выполняется сохранёнными датами в самой системе Battle Pass.

Проверки: изолированный PostgreSQL/PGlite с существующими production-функциями XP и SP, управляемой датой BP, настоящими RPC комнат/Вордли/предиктов; отдельно проверены день до активации, следующие дни, повторные события и суммы 10 XP/150 SP. HTTP-тест проверяет отображение задач из расписания базы и правильные названия/прогресс.

## Дневной лимит XP

`20261106000905_tic_tac_toe_daily_xp_cap.sql` ограничивает только XP из `tic_tac_toe_win`: сумма за московский день не превышает 30. Учитываются уже записанные события текущего дня; чужие источники XP не расходуют квоту. Блокировка на аккаунт сериализует проверку лимита и начисление. Новый день определяется в часовом поясе Europe/Moscow, история и уровень не обнуляются. Задание Battle Pass проверяется независимо от достигнутого лимита XP.
