# NIGHT RUN

`/games/night-run` — свободная аркада без платы за вход и без проигрыша баланса. Три полосы, стрелки/A-D, кнопки и свайпы. На дороге появляются препятствия; после ~42 секунд иногда закрыты две полосы, но остаётся безопасная. Столкновение завершает забег. Время и дистанция относятся к сохранённой симуляции (10 шагов в секунду), а не к часам устройства.

Раз в 600 шагов (60 секунд) появляется **одна монета** на определённой полосе. На строке монеты препятствий нет. Если игрок находится на её полосе при пересечении, начисляется 1 обычная монета через `rewards_coin_transactions` (`adjustment`, примечание `NIGHT RUN`). Баланс отображается в инвентаре аккаунта. Это не отдельный скин или предмет. Если монета пропущена, начисления нет. Платы, ставок и ежедневного лимита наград нет; один активный забег на пользователя. Уже подтверждённые награды сохраняются при столкновении или остановке.

## Серверная проверка

Сервер выбирает seed, сохраняет игру и принимает пакеты выбранных полос (до 30 шагов). SQL воспроизводит движение по одной полосе за шаг, препятствия и подбор монет; клиент не задаёт сумму, координаты монеты или результат. Время шага не может опередить серверные часы. Отсутствие подтверждения 8 секунд или отставание симуляции более 5 секунд завершает забег. Данные другого аккаунта недоступны; идентификатор пользователя берётся из проверенной сессии Twitch.

Все изменяющие RPC сначала блокируют пользователя, затем игру — тот же порядок блокировки кошелька. Прогресс и запись начисления фиксируются атомарно. `(game_id, minute)` уникален; повтор старого checkpoint возвращает текущее состояние без повторной выплаты. Один активный забег обеспечен частичным уникальным индексом. Таблицы закрыты RLS и REVOKE для браузерных ролей, RPC — `SECURITY INVOKER`, пустой search_path, только service_role. HTTP проверяет Origin, тип JSON, форму тела и лимит запросов.

Клиент обновляет сервер примерно раз в 2 секунды и немедленно при подборе/столкновении/остановке. Потерянный ответ повторяется с прежним checkpoint и входами. HUD «Зачислено» показывает подтверждённые монеты. При скрытии страницы клиент завершает забег; при потере связи подтверждённые монеты остаются. Возобновление короткой перезагрузки возможно до истечения серверного окна. Не обещается автономная офлайн-игра.

Эта проверка предотвращает ускоренные начисления, подмену награды и повторные выплаты. Она не доказывает, что ввод выполняется человеком: продвинутый бот может имитировать допустимое управление в реальном времени. Ни «полной защиты от ботов», ни проверки физического устройства здесь не заявляется.

## Проверено

PGlite: совпадение SQL и клиентской физики на нескольких минутах, реальные/пропущенные монеты, повтор checkpoint, откат при невозможности записать кошелёк, сохранение награды после столкновения/таймаута, заблокированные пользователи и права ролей. UI: клавиатурные/сенсорные кнопки, путь до минутной монеты, потеря ответа с повтором и подтверждённый баланс. Полный HTTP-сервер: аутентификация, Origin, запрет клиентской награды и ссылка в разделе «Игры». Визуальный прогон на физических телефонах не выполнялся. Реальные игровые награды на production при проверке не создавались.

Миграция создана через поддерживаемый MCP и сохранена с версией истории БД: локальный Supabase CLI 3.0.0 аварийно завершался в этой среде; попытки 2.75.0 также не смогли создать файл. Схема проверена на изолированной БД до применения. Юридические черновики прежней задачи не публиковались вместе с игрой.
