# Игры / Вордли

В меню кабинета: Промокод → Игры → Апгрейдер. Первая игра — русское слово из 5 букв, 6 попыток, одна игра на аккаунт в сутки по Москве. Ё = Е. Бесплатно, без начисления наград.

Используется предоставленный список из 140 слов: 7 групп по 20 слов в указанном порядке. Понедельник — слова 1–20, вторник — 21–40, …, воскресенье — 121–140; группы повторяются каждую неделю по московскому календарю. На первой принятой попытке сервер случайно выбирает один из них и сохраняет его для пользователя. У разных игроков возможны совпадения; общего слова для всех нет. Ответ доступен браузеру только после завершения игры.

Прогресс сохраняется в Supabase. Уникальный ключ аккаунт/дата, блокировка строки и идентификаторы запросов защищают от повторов, гонок и обхода перезагрузкой. Таблица и RPC доступны только service_role. Авторизация использует существующую подписанную Twitch-сессию.

## Выпуск

1. Применить `supabase/migrations/20261105201910_games_wordly.sql` в проекте d1psy-rewards. Миграция добавляет только отдельную таблицу и функцию, существующие данные не меняет.
2. Выполнить `npm ci`, `npm test`, `npm run build`.
3. После слияния ветки развернуть обычный сервис Render с `npm start`. Новые переменные окружения не нужны; используются SUPABASE_URL, SUPABASE_SECRET_KEY, SESSION_SECRET.
4. Через обычный аккаунт проверить меню, ввод и восстановление прогресса. Без авторизации API и страницы игры возвращают 401.

Откат приложения совместим с новой таблицей: она остаётся неиспользуемой. Не удалять таблицу с пользовательскими играми при откате кода.

## Проверки

`npm test`: граница 00:00 МСК, смена года, набор из 20 слов для каждого из семи дней, повторяющиеся буквы, сокрытие ответа; выполнение SQL в изолированном Postgres (PGlite), повтор запроса, лимит 6 попыток, завершение победой, отклонение устаревшего дня, права anon/authenticated/service_role.

Дополнительно проверены фактическая цепочка HTML-обработчиков полного приложения, порядок ссылок и выполнение клиентского скрипта в DOM. Визуальная проверка Chromium в этой среде недоступна: загрузка браузера вернула повреждённый архив. Перед выпуском рекомендуется посмотреть страницу на телефоне.
